# 🏘️ Denim Village

หมู่บ้าน 3D Low-Poly สร้างด้วย AI 100% — เขียนโค้ดทั้งหมดโดย Hermes Agent

> เปิดไฟล์เดียวก็เล่นได้เลย — ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต

## 🎮 วิธีเล่น

1. ดาวน์โหลด `index.html`
2. เปิดด้วยเบราว์เซอร์ (Chrome / Edge / Firefox)
3. เล่นเลย! 🖱️ ลากหมุนกล้อง · ล้อเลื่อนซูม

## ✨ ฟีเจอร์

- 🏘️ หมู่บ้าน 3D: ถนน Grid, บ้าน 5 หลัง, คาเฟ่, ร้านซ่อม, น้ำพุ, สวน, ทะเลสาบ
- 👑 ตัวละคร AI "คิม" & "เมเม่" เดินทำงานในเมือง (ช่างซ่อม / บาริสต้า)
- 🚶 NPC ชาวบ้าน 3 คน + สัตว์เลี้ยงเดินเล่นอัตโนมัติ
- 🧠 ระบบเดินอัจฉริยะ: หลบสิ่งก่อสร้าง, เดินบนทางเท้า, ข้ามถนนได้
- 🌗 กลางวัน/กลางคืน — โคมไฟถนน + ไฟหน้าต่างติดตอนกลางคืน
- 🎵 ดนตรีบรรเลง (กดปุ่มเปิด)
- 🚗 รถวิ่งรอบเมือง
- 🗨️ ช่องแชทคุยกับชาวบ้าน

โปรเจคนี้เขียนโค้ดทั้งหมดโดย **Hermes Agent** (คิม) — ตั้งแต่ผังเมือง ตัวละคร ระบบเดิน ไปจนถึงดนตรี
